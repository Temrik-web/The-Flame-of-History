# Справочная страница проекта

`web-ui` — отдельная статическая страница с кратким описанием Unity-проекта и кнопками копирования команд проверки и сборки. Она не управляет запущенной игрой и не показывает состояние Unity в реальном времени. Основной продукт находится в корне репозитория.

```powershell
npm install
npm run dev
```

Для готовой страницы используйте `npm run build`. Команды, которые копирует страница, выполняются из корня Unity-проекта; требования к ним приведены в корневом `README.md`.
